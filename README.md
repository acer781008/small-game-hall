## V1.5 共通規格

### 主控分頁

- 🎮 遊戲管理：淡藍色
- 🎁 獎品設定：淡橘色
- 📋 得獎紀錄：淡粉色
- 👥 玩家紀錄：淡綠色
- 分頁文字固定使用深色，維持高對比。

### 每位玩家可完成次數

主控「本場活動」只設定一次 **每位玩家可完成次數**，套用到所有遊戲。

- 時間到／未完成：不計完成次數，可重新挑戰。
- 成功完成：才計 1 次。
- 達到上限後：該玩家不能再開始該款遊戲的新一局。
- 參與紀錄仍會記錄每次真正開始的遊戲局數。

### 時間規則

所有遊戲統一：

- 有時間限制：玩家顯示「剩餘時間」往下倒數。
- 不限時間：從 `00:00` 往上計時。
- 成功完成：一律由伺服器記錄實際完成時間。
- 主控的整局遊戲時間以「分鐘」設定；像賓果叫號間隔、拼圖看原圖 3 秒這類動作時間仍保留秒數。

### 完成排行榜

每款玩家頁下方都有「🏆 完成排行榜」：

- 只顯示成功完成玩家。
- 依最快完成時間排序。
- 顯示排名、玩家、最快完成時間、完成次數。
- 預設每 5 秒自動更新，完成後也會立即刷新。

### 時間到與完成後按鈕

- 時間到未完成：顯示「🔄 重新開始」與「🏠 返回遊戲廳」。
- 成功完成：顯示「🏠 返回遊戲廳」。

## 本機啟動

Windows CMD：

```bat
set ADMIN_PASSWORD=你自己設定的主控密碼
npm install
npm start
```

Git Bash：

```bash
export ADMIN_PASSWORD='你自己設定的主控密碼'
npm install
npm start
```

啟動後：

- 玩家：`http://localhost:3000/`
- 主控：`http://localhost:3000/admin-login.html`

## 資料保存

- 沒有 `DATABASE_URL`：使用本機 JSON，適合本機測試。
- 有設定 `DATABASE_URL`：使用 PostgreSQL 永久保存，適合 Render 正式部署。
- 主控密碼請用 `ADMIN_PASSWORD` 環境變數，不要寫死在程式碼裡。

## 更新舊版時

若要保留目前活動碼、獎品與玩家紀錄，請使用 **V1.5 更新包** 覆蓋程式檔；更新包不包含 `data/`，不會主動覆蓋既有 JSON 測試資料。
