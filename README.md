# 小遊戲館測試版 V0.6

目前整合 4 款：
- 賓果 V22.9
- 數獨 Mini V1.4
- 翻牌 V1.3 無積分獎品準備版
- 貨架整理 V1.2.20 移除玩具店版

## 統一架構
- 同一個網站、同一個 Render 服務、同一個主控登入。
- 主控最上方只有一個「活動碼」。
- 可產生新活動碼、複製玩家網址、複製分享文字。
- 共用備註放在遊戲館主控，不再由每款遊戲重複設定。
- 每款遊戲只保留「開放/關閉」和自己的玩法設定。
- 玩家網址會自動帶活動碼，不需要每款遊戲再輸入房號。

## 獎品
- 無積分。
- 玩家在時間內完成該遊戲條件後，自動從本場活動剩餘獎品中隨機發 1 份。
- 隨機權重依獎品剩餘數量計算。
- 可設定每位玩家最多得獎 1/2/3 次或不限。
- 新活動碼會使用全新的獎品池與得獎紀錄。

## 得獎紀錄
只記錄：玩家｜完成遊戲｜獲得獎品｜得獎時間，並可一鍵複製。

## 本機測試
```bash
npm install
npm start
```
開啟： http://localhost:3000
主控： http://localhost:3000/admin-login.html
預設主控密碼：2468
主控密碼統一由部署環境變數 `ADMIN_PASSWORD` 設定；網站內不提供設定或修改密碼功能。


## V0.6 新增
- 共用活動可選「開賽日期＋時間」與「結束日期＋時間」。
- 未設定開賽時間＝立即開放；未設定結束時間＝不限結束。
- 玩家首頁會顯示活動狀態與開賽倒數，未開始／已結束時禁止開始新遊戲。
- 小遊戲館首頁、主控後台、主控登入頁改為繽紛卡片風格與小圖案點綴。


## V0.9
- 主控後台、獎品設定、得獎紀錄、主控登入頁套用可愛繽紛統一風格。
- 僅調整視覺與排版，活動碼、遊戲設定、獎品與得獎邏輯不變。


## V0.9 新增
- 主控遊戲卡片改成和玩家首頁相同的可愛繽紛卡片風格。
- 第一次啟動不再使用固定 2468；會要求主控自行設定密碼。
- 密碼只保存雜湊與 salt，不以明碼寫在程式中。


### 主控密碼
- Render：在服務的 Environment 中新增 `ADMIN_PASSWORD`，值填你自己的主控密碼。
- 本機測試：可在專案根目錄建立 `.env`，內容例如 `ADMIN_PASSWORD=2468`。
- 網站內不提供「設定密碼」或「修改密碼」按鈕。
