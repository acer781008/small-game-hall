# 小遊戲館 V1.6 測試版

這版以 V1.5.3 為穩定底版，保留後續確認有效的修正，再加入 C 模式獎品與玩家自選功能。

## 本版重點

### C 模式獎品
- 獎品模式新增 C：依難度／盤面分成 C1、C2、C3。
- C1／C2／C3 每級可新增多個獎品與數量。
- 玩家在時間內完成後，直接從對應級別獎池自動發獎並扣庫存。
- 玩家頁會顯示「目前 C 模式獎項」、各獎品名稱與剩餘數量；目前玩法對應級別會突出。
- C 模式得獎紀錄與 A／B 分開；複製時只複製目前分頁。

### 玩家自選
每款遊戲都可以由主控決定是否允許玩家自選。開啟時，玩家只看到主控勾選開放的玩法／盤面／難度／主題／分類；遊戲時間仍由主控設定。

- 賓果：素材、盤面、玩法；包含「麻將圖片」。
- 數獨：玩法、9×9／12×12、難度。
- 翻牌：題型、盤面。
- 貨架整理：主題、難度。
- 連連看：主題、難度。
- 拼圖：盤面、圖片分類。

### 拼圖
- 原本 10 張拼圖圖片全部移除。
- 改成 37 張本機 JPG 素材，共 6 類：可愛動物、海洋世界、森林／農場、樂園／甜點、冬季／極光、旅行／風景。
- 玩家只選「分類」，按開始後由伺服器從該分類隨機抽 1 張，不會看到 37 個圖片名稱選單。
- 完成紀錄會保留分類、盤面與實際抽到的圖片名稱。

### 手機／既有問題修正
- 翻牌：保留自動重連，並補回盤面建立所需的 `fmt / hash / shuffle`，修正按開始後已計局數但盤面不出現。
- 連連看：保留 V1.5.4 已確認的手機版 CSS，盤面縮進手機寬度，不需左右拖動；上方資訊區縮小。
- 賓果：種菜素材改成本機 PNG 為主要來源，不再先讀 WebP；載入失敗會加快取參數重試一次。144 張 PNG 都保留。
- 貨架整理：遊戲時間改成與其他遊戲一致的分鐘制；有限時倒數，不限時從 00:00 往上計時，完成記錄實際時間。

### 主控登入
- 登入成功後使用 7 天有效的簽章 HttpOnly Cookie。
- Render 休眠／Node.js 重新啟動後，只要 `ADMIN_PASSWORD` 沒有改，重新整理仍可保持主控登入。
- 主控密碼仍只從 `ADMIN_PASSWORD` 環境變數讀取，不寫死在程式碼。

## 共通規格
- 主控四個主分頁維持：遊戲管理淡藍、獎品設定淡橘、得獎紀錄淡粉、玩家紀錄淡綠。
- 「每位玩家可完成次數」仍是每款遊戲各自計算；失敗或時間到不計完成次數。
- 有限時顯示剩餘時間；不限時從 00:00 往上計時；成功完成一律記錄實際完成時間。
- 每款遊戲玩家頁保留共用完成排行榜。
- 時間到可重新開始或返回遊戲廳；成功後可返回遊戲廳。

## 本機啟動

Git Bash：

```bash
export ADMIN_PASSWORD='你自己設定的主控密碼'
npm install
npm start
```

玩家：`http://localhost:3000/`

主控：`http://localhost:3000/admin-login.html`

## 資料保存
- 沒有 `DATABASE_URL`：使用本機 JSON，適合本機測試。
- 有 `DATABASE_URL`：使用 PostgreSQL 永久保存，適合 Render 正式部署。
- V1.5.3 → V1.6 更新包不包含 `data/`、`.env` 或執行期間產生的遊戲紀錄檔，避免覆蓋現有資料。

## 注意
本版已做程式語法、素材完整性與核心流程檢查；不同手機瀏覽器（尤其 Facebook／LINE 內建瀏覽器）的實際畫面與觸控仍建議在正式上線前用手機測一次。

## V1.6 beta.4｜C 模式每款遊戲獨立獎池
- C 模式不再全館共用 C1／C2／C3。
- 賓果、數獨、翻牌、貨架整理、連連看、拼圖，各自擁有獨立 C1／C2／C3 獎池。
- 每個「遊戲＋C級」可新增多個獎品與數量；完成後只從該池剩餘獎品隨機發放並扣 1。
- 玩家端「獎品說明」只顯示目前遊戲自己的 C 獎品。
- 改版前未分類的舊 C 獎品會保留，主控可指定遊戲後移入，不會直接被誤發。
